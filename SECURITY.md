# Security / takedown policy

If you find game binaries, dumps, disassembly, decompiled code or other copyrighted game data in this repository (or in a pull request), please **do not repost it**. Report it privately via GitHub's "Report a vulnerability" (Security tab) or open an issue that only names the file path, and a maintainer will remove it and purge history if needed.

Bugs in the validator that let prohibited content through are treated as security issues.
